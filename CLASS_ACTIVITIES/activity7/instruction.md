## Activity: Phonebook Management System (Maven & CSV)

### Objective

Develop a Java application using **Maven** to manage a Phonebook. You will use a `HashMap` for data storage and implement **File I/O** to persist your contacts to a `.csv` file.

### What is a Service Layer?

The `PhonebookService` acts as the "logic hub" of your application. Instead of writing all your code in the entry-point class, the Service handles the technical details of managing the `HashMap` and writing to the disk.

* **The Main/App Class**: Handles user interaction (menus, scanning input).
* **The Service Class**: Handles data processing (adding to the map, formatting CSV lines).

---

### Technical Specifications

1. **Project Structure (Maven)**:
Your project must follow the standard `src/main/java` directory layout. Organize your code as follows:
* `com.phonebook`: Contains your entry-point class (e.g., `Main` or the Maven-generated `App`).
* `com.phonebook.models`: Contains the `Contact` data class.
* `com.phonebook.services`: Contains the `PhonebookService` (Logic & File I/O).


2. **Data Models (`com.phonebook.models`)**:
* **`Contact` Class**: Private fields for `name`, `phoneNumber`, and `email`.
* Include a constructor, getters, and setters.
* **Method**: `toCsvString()` – returns a String formatted for a CSV file (e.g., `Jane Doe,555-0101,jane@example.com`).


3. **The Service Layer (`com.phonebook.services`)**:
* **`PhonebookService` Class**:
* Contains a `private HashMap<String, Contact> contacts`.
* Methods: `addContact(Contact c)`, `searchContact(String name)`, and `removeContact(String name)`.
* **`saveToCSV(String filename)`**: Iterates through the `HashMap` values and writes them to a file. Use **try-with-resources** to ensure the `FileWriter` or `BufferedWriter` closes properly.




4. **The Entry Point (`com.phonebook`)**:
* Use the class containing the `public static void main` method (this may be the `App` class autogenerated by Maven).
* Instantiate `PhonebookService` and implement a `Scanner`-based menu:
1. Add | 2. Search | 3. Remove | 4. Display All | 5. Save to CSV | 0. Exit





---

### Instructions for Students

1. **Maven Setup**: Create a Maven project. Your source code must follow the package paths exactly as defined above.
2. **Implementation Order**:
* Create the `Contact` class first.
* Build the `PhonebookService` to handle the map logic and file writing.
* Update the Maven-generated class (or create a `Main` class) in `com.phonebook` to handle the menu and user input.


3. **File Persistence**: The CSV file should be created in the project root. Ensure you handle `IOException` using a try-catch block within the service.
4. **Submission Requirements**:
* Create a folder named **`activity7`**.
* Place **only** your source code (`.java` files) and your generated **`contacts.csv`** (with at least 3 sample entries) into this folder.
* Do **not** submit the entire Maven project, `pom.xml`, or the `target` folder.
